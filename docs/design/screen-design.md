# 画面設計

## 画面一覧

| # | 画面名 | パス | ロール | 説明 |
|---|--------|------|--------|------|
| 1 | ログイン | /login | 全員 | 社員番号＋パスワード |
| 2 | ダッシュボード | / | 全員 | 当日の打刻状況・打刻ボタン |
| 3 | 勤怠一覧 | /attendance | 全員 | 月次カレンダー形式で自分の勤怠表示 |
| 4 | 打刻修正申請 | /attendance/corrections | 全員 | 修正申請の作成・一覧 |
| 5 | 打刻修正承認 | /admin/corrections | 管理者 | 申請の承認/却下 |
| 6 | 休暇申請 | /leaves | 全員 | 休暇申請の作成・一覧・残日数表示 |
| 7 | 休暇承認 | /admin/leaves | 管理者 | 申請の承認/却下 |
| 8 | 月次レポート | /admin/reports | 管理者 | 部署別・社員別の月次集計 |
| 9 | 社員管理 | /admin/employees | 管理者 | 社員一覧・登録・編集 |
| 10 | 部署管理 | /admin/departments | 管理者 | 部署ツリーの表示・編集 |

## コンポーネント構成

```
src/
├── app/
│   ├── layout.tsx              # 共通レイアウト（ヘッダー・ナビ）
│   ├── page.tsx                # ダッシュボード
│   ├── login/page.tsx          # ログイン
│   ├── attendance/
│   │   ├── page.tsx            # 月次勤怠一覧
│   │   └── corrections/page.tsx # 打刻修正申請
│   ├── leaves/page.tsx         # 休暇申請
│   └── admin/
│       ├── corrections/page.tsx # 打刻修正承認
│       ├── leaves/page.tsx     # 休暇承認
│       ├── reports/page.tsx    # 月次レポート
│       ├── employees/
│       │   ├── page.tsx        # 社員一覧
│       │   └── [id]/page.tsx   # 社員編集
│       └── departments/page.tsx # 部署管理
├── components/
│   ├── ui/                     # 汎用UIコンポーネント
│   ├── attendance/             # 勤怠関連コンポーネント
│   ├── leave/                  # 休暇関連コンポーネント
│   └── admin/                  # 管理画面コンポーネント
├── hooks/                      # カスタムhooks
└── lib/
    ├── api-client.ts           # API通信ラッパー
    └── types.ts                # API型定義
```
