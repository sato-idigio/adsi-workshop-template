# 勤怠管理システム — 要求仕様書

## 概要

社員の出退勤打刻・勤怠管理・休暇管理を行う Web アプリケーション。
フレックスタイム制（スーパーフレックス）に対応し、1000人以上の利用を想定する。

## ロールと権限

| ロール | 説明 | 権限 |
|--------|------|------|
| 一般社員 | 全社員 | 自身の打刻・勤怠確認・休暇申請・打刻修正申請 |
| 管理者 | 人事含む | 全社員の勤怠閲覧・承認・月次レポート閲覧・社員管理・部署管理 |

## ユーザーストーリー

### 認証

- US-01: 社員として、社員番号とパスワードでログインしたい。自分の勤怠情報にアクセスするために。
- US-02: 社員として、ログアウトしたい。セキュリティを確保するために。

### 打刻

- US-10: 社員として、Web画面のボタンで出勤打刻したい。勤務開始を記録するために。
- US-11: 社員として、Web画面のボタンで退勤打刻したい。勤務終了を記録するために。
- US-12: 社員として、当日の打刻状況を確認したい。打刻漏れに気づくために。

### 打刻修正

- US-20: 社員として、打刻を修正する申請を出したい。打刻忘れや誤りを訂正するために。
- US-21: 管理者として、部下の打刻修正申請を承認/却下したい。正確な勤怠記録を維持するために。

### 勤怠一覧

- US-30: 社員として、自分の月次勤怠一覧を確認したい。労働時間を把握するために。
- US-31: 管理者として、全社員の月次勤怠一覧を確認したい。労務管理を行うために。

### 休暇管理

- US-40: 社員として、有給休暇を申請したい。休暇を取得するために。
- US-41: 社員として、半休（午前半休・午後半休）を申請したい。部分的に休むために。
- US-42: 社員として、特別休暇を申請したい。慶弔等の特別な事由で休むために。
- US-43: 社員として、代休を申請したい。休日出勤の代わりに休むために。
- US-44: 管理者として、休暇申請を承認/却下したい。チームの稼働を管理するために。
- US-45: 社員として、有給休暇の残日数を確認したい。取得計画を立てるために。

### 月次レポート

- US-50: 管理者として、月次勤怠集計レポートを閲覧したい。労務状況を把握するために。

### 社員管理

- US-60: 管理者として、社員を登録したい。新入社員の勤怠管理を開始するために。
- US-61: 管理者として、社員情報を編集したい。異動等の変更を反映するために。
- US-62: 管理者として、部署を管理したい。組織構造を維持するために。

## 業務ルール

### フレックスタイム制

- スーパーフレックス（コアタイムなし、フレキシブルタイム制限なし）
- 清算期間: 1ヶ月
- 所定労働時間: 8時間/日

### 残業計算

- 1日8時間超の労働を残業とする
- 深夜残業（22:00〜5:00）を区別して記録する

### 有給休暇

- デモ用に全社員一律20日/年を付与
- 半休: 0.5日として計算
- 申請→直属上長が承認（1段階）

### 休暇種別

| 種別 | 説明 | 日数消費 |
|------|------|----------|
| 有給休暇 | 年次有給 | 残日数から減算 |
| 半休（午前） | 午前のみ休暇 | 0.5日 |
| 半休（午後） | 午後のみ休暇 | 0.5日 |
| 特別休暇 | 慶弔等 | 消費なし（別枠） |
| 代休 | 休日出勤の振替 | 消費なし（別枠） |

### 承認フロー（打刻修正・休暇共通）

```
社員が申請 → 直属上長（管理者）が承認/却下
```

- 1段階承認
- ステータス: 申請中 → 承認済 / 却下

| 氏名 | 姓名 | |
| メールアドレス | | 通知用 |
| 部署 | 所属部署 | 部署マスタ参照 |
| 役職 | | |

## 部署構造

- 最大3階層: 本部 → 部 → 課
- 社員は末端の部署に所属する

## 月次集計データ（将来の給与連携を考慮）

| 項目 | 説明 |
|------|------|
| 総労働時間 | 月の合計労働時間 |
| 残業時間 | 1日8時間超の合計 |
| 深夜時間 | 22:00〜5:00 の労働時間合計 |
| 休日出勤時間 | 休日に出勤した時間の合計 |
| 有給取得日数 | 月内の有給消化日数 |

## 非機能要件

| 項目 | 要件 |
|------|------|
| 利用者数 | 1000人以上 |
| 対応ブラウザ | PC ブラウザ（モバイル非対応） |
| オフライン | 非対応 |
| CSV/Excel出力 | 不要 |
| 給与連携 | 今回対象外（データ構造のみ準備） |

## MVP スコープ

以下を最初のリリースに含める:

1. **認証**（ログイン・ログアウト）
2. **打刻**（出勤・退勤）
3. **勤怠一覧**（自分の月次一覧）
4. **休暇管理**（有給・半休・特別休暇・代休の申請・承認）
5. **打刻修正**（申請・承認）
6. **月次レポート**（管理者向け集計閲覧）
7. **社員管理**（登録・編集）
8. **部署管理**

## 技術スタック

- Backend: Java / Spring Boot
- Frontend: TypeScript / Next.js
- DB: PostgreSQL（Flyway マイグレーション）
- 認証: Spring Security（社員番号＋パスワード）
