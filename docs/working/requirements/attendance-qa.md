# 勤怠管理アプリ — 要求仕様 Q&A

## 対象ユーザー

[Question] このアプリの利用者は誰ですか？（例: 一般社員のみ / 社員＋管理者 / 社員＋管理者＋人事）
[Answer]社員＋管理者＋人事

[Question] 想定利用人数はどのくらいですか？（例: 10人規模 / 100人規模 / 1000人以上）
[Answer]1000人以上

## 基本機能

[Question] 必要な打刻の種類を教えてください。（例: 出勤・退勤のみ / 出勤・退勤・休憩開始・休憩終了）
[Answer]出勤・退勤のみ

[Question] 打刻方法は？（例: Web画面のボタンのみ / ICカード連携 / GPS付き）
[Answer]Web画面のボタンのみ

[Question] 打刻の修正（申請・承認）機能は必要ですか？
[Answer]必要。      

## 勤務形態

[Question] 勤務形態はどれですか？（例: 固定時間制のみ / フレックス / シフト制 / 複数対応）
[Answer]フレックス

[Question] 所定労働時間は何時間ですか？（例: 8時間 / 7.5時間）
[Answer]8時間

[Question] 残業の計算は必要ですか？（法定内残業・法定外残業の区別が必要か）
[Answer]必要

## 社員管理

[Question] 社員IDは自動採番ですか？それとも手動入力（社員番号）？
[Answer]手動入力

[Question] 社員の属性として必要な情報は？（例: 氏名・メールアドレス・部署・役職）
[Answer]氏名・メールアドレス・部署・役職・社員番号

[Question] 部署の階層構造は必要ですか？（例: 不要 / 1階層 / 複数階層）
[Answer]複数階層

## 休暇管理

[Question] 有給休暇の管理機能は必要ですか？
[Answer]必要

[Question] その他の休暇種別は？（例: 半休・特別休暇・代休・振替休日）
[Answer]半休・特別休暇・代休

## レポート・集計

[Question] 月次の勤怠集計レポートは必要ですか？
[Answer]必要

[Question] CSV / Excel エクスポート機能は必要ですか？
[Answer]不必要

[Question] 給与計算システムとの連携は必要ですか？
[Answer]必要(今回は連携対象外)

## 認証・権限

[Question] ログイン方式は？（例: メール＋パスワード / SSO / 社員番号＋パスワード）
[Answer]社員番号＋パスワード

[Question] 権限のロール分けはどうしますか？（例: 一般社員・管理者の2ロール / より細かい分割）
[Answer]一般社員・管理者の2ロール

## 技術要件

[Question] モバイル対応は必要ですか？（レスポンシブ Web / ネイティブアプリ）
[Answer]不必要          

[Question] オフライン対応は必要ですか？
[Answer]不必要

## スコープ

[Question] MVP（最初のリリース）に含めたい機能の優先順位を教えてください。（例: まず打刻と勤怠一覧が見えればOK / 休暇管理まで必要）
[Answer]まず打刻と勤怠一覧+休暇管理まで必要
